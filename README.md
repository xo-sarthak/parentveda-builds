# ParentVeda test builds

Android test builds of ParentVeda. This repository holds no source code, only release downloads.

Newest build: https://github.com/xo-sarthak/parentveda-builds/releases/latest/download/ParentVeda.apk

To install: open the link on an Android phone, download ParentVeda.apk, tap it, and allow "Install unknown apps" for the browser if asked.
